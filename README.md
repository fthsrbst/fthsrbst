## About Me

I am a software engineer based in Istanbul, working at the intersection of **offensive security**, **privacy-focused systems**, and **agentic AI**.

My experience includes web application and internal network security testing, security automation, backend development, and distributed desktop applications. I am particularly interested in systems with explicit trust boundaries, scoped execution, auditable state, and safe defaults.

## Featured Projects

| Project | Description |
|---|---|
| [**TIRPAN**](https://github.com/fthsrbst/TIRPAN) | Autonomous cybersecurity agent built around a ReAct-style loop and more than 30 security tools. Includes scope enforcement, destructive and DoS restrictions, a kill switch, and CVSS-scored reporting. |
