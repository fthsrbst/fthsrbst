## Selected projects

### [Mnema](https://github.com/fthsrbst/mnema)

A shared memory and context server for AI agents. It lets different development tools access the same decisions, documents, and project context through MCP and REST.

The retrieval layer combines SQLite FTS5 keyword search with vector search. Working on Mnema gives me a practical setting for exploring document retrieval and the information an agent needs to continue a task.

*TypeScript · SQLite · RAG · MCP*

### [lmstudio-ollama-mcp](https://github.com/fthsrbst/lmstudio-ollama-mcp)

An experimental coding agent for local models through LM Studio, Ollama, and llama.cpp. The project explores model routing, hardware-aware execution, and parallel agents.

*TypeScript · Local inference · Agent tooling*

### [TIRPAN](https://github.com/fthsrbst/TIRPAN)

My graduation project: an LLM-driven agent for authorized security testing. It uses a ReAct-style loop to work with security tools and produce structured findings and reports.

The project connects my security background with agent development, including tool integration, execution scope, and action logging.

*Python · FastAPI · Tool use · Security automation*
